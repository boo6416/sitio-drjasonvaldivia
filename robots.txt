#
# Los tres rastreadores de OpenAI son INDEPENDIENTES entre sí:
#   · OAI-SearchBot  → alimenta las respuestas de ChatGPT. Bloquearlo = NO
#                      aparecer en ChatGPT. Es el que decide la visibilidad.
#   · GPTBot         → entrenamiento de modelos.
#   · ChatGPT-User   → cuando un usuario pide expresamente abrir esta página.
#
# Si algún día se decide no ceder contenido para entrenamiento, se bloquea
# GPTBot y se dejan los otros dos. NO se toque OAI-SearchBot.
#
# Un cambio aquí tarda ~24 h en reflejarse del lado de OpenAI.
